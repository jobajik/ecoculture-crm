# Ecoculture-CRM

CRM для приёма заявок и отгрузки цветка (розы, хризантемы, эустома) с тепличного/производственного
склада.

**Рабочий адрес:** https://ecoculture-crm.vercel.app

- Все данные хранятся в Google Таблице — видно и правится вручную при необходимости.
- Вход — через корпоративный Google-аккаунт (Google OAuth), роли: **менеджер**, **зав. складом**, **администратор**.
- Два производства: **Rose Farm** (розы, эустома) и **Есентай Агро Хим** (хризантема). У каждого свой
  зав. складом — он видит остатки, принимает партии, отгружает и печатает сводную заявку только по
  своему цветку. Менеджеры и администратор работают по обоим.
- Приём заявок менеджером, отгрузка и приёмка партий зав. складом с учётом даты сбора (FIFO).
- Сводная заявка склада на день — на одну страницу A4, отдельно по каждому производству, с колонками
  по менеджерам и клиентам.
- Аналитика: остатки, сроки хранения и алерты по просрочке, продажи менеджеров против плана,
  дневной дашборд, разбивка по производствам, динамика цен, списания.

Подробная пошаговая инструкция по настройке Google Cloud, Google-таблицы и деплою на хостинг — в файле **[SETUP.md](./SETUP.md)**. Начните с него.

## Стек

Next.js 14 (App Router, TypeScript) · NextAuth.js (Google OAuth) · Google Sheets API · Tailwind CSS · Recharts.

## Быстрый старт (после настройки .env.local по SETUP.md)

```bash
npm install
npm run setup-sheet   # один раз — создаёт вкладки в таблице
npm run dev           # http://localhost:3000
```

## Структура проекта

```
src/
  app/                 страницы (App Router) и server actions
    orders/             заявки: список, создание, детали
    warehouse/           склад: очередь на отгрузку, приёмка, партии, списание
    analytics/          дашборд аналитики
    admin/               сотрудники/роли и сроки хранения (только чтение — правится в таблице)
  components/          переиспользуемые UI-компоненты и графики
  lib/
    sheets.ts            низкоуровневый клиент Google Sheets API
    repo/                CRUD-функции по каждой вкладке таблицы
    analytics.ts         агрегация данных для дашборда
    shelfLife.ts         расчёт сроков хранения и статусов партий
    auth.ts              конфигурация NextAuth
scripts/setup-sheet.ts  создание вкладок и заголовков в новой таблице
```
